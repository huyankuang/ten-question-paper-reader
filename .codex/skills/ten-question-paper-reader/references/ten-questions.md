# 十问精读框架（定义与输出模板）

## 十个问题

| # | 问题 | 类型 |
|---|------|------|
| 1 | 这篇文献的核心研究主题是什么？聚焦哪个具体的工程/学术问题？ | 客观提取 |
| 2 | 作者为什么要做这项研究？前人工作留下了什么未解决的缺口？ | 客观提取 |
| 3 | 本文的整体研究思路/技术路线是什么？大致分为哪几个核心步骤？ | 客观提取 |
| 4 | 本文采用的核心研究方法/模型/实验方案是什么？关键参数有哪些？ | 客观提取 |
| 5 | 研究使用的数据集/样本/试验对象来自哪里？数量和代表性如何？ | 客观提取 |
| 6 | 本文最终得到了哪些主要结论和关键定量结果？ | 客观提取 |
| 7 | 这项工作的核心创新点/学术贡献是什么？和已有研究最大区别在哪？ | 客观+分析 |
| 8 | 研究存在哪些局限性？有哪些场景/因素没有考虑到？ | 客观+分析 |
| 9 | 本文的结论能应用到什么场景？有什么工程价值或学术参考意义？ | 分析+应用 |
| 10 | 我读这篇文献的核心收获是什么？有哪些方法/结论可以直接复用？ | 主观沉淀 |

> Q1–Q6 是客观提取，答案必须能在原文找到出处；Q7–Q9 需要分析；Q10 是用户自己的主观沉淀，不由 AI 代笔。

## 每个问题的输出结构

```
### Q{n}. {问题}
- 类型：{类型}
- 置信度：高/中/低
- 原文定位：第 X 节 / 第 X 页 / 表 X / 图 X（无法定位时写"原文未明确"）
- 精简版：1–2 句核心结论
- 详细版：展开回答，保留关键定量数据
```

## 最终 Markdown 笔记模板

```markdown
# 精读笔记：{论文标题}

## 一、十问拆解
（按上面的逐问结构列出 Q1–Q10）

## 二、我的总结
（用户自己写的总结原文）

## 三、AI 评价
- 总分：{score}/100
- 核心问题把握：{x}/25
- 方法逻辑理解：{x}/25
- 结论数据匹配：{x}/25
- 创新点识别：{x}/25
**优点**：…
**改进建议**：…

## 四、核心术语表
- **{术语}**：{一句话定义，注明首次出现页码}
```

## 评价四维度（evaluate 子命令产出）

1. 核心问题把握准确度
2. 方法逻辑理解清晰度
3. 结论与数据匹配度
4. 创新点识别精准度

每项 25 分，合计 100 分。
