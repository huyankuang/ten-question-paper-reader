# 十问精读框架 v0.2（定义与输出模板）

## 十个问题（v0.2 精简重组）

| # | 问题 | 类型 |
|---|------|------|
| 1 | 核心研究主题是什么？聚焦哪个具体问题？ | 客观提取 |
| 2 | 作者为什么做？前人留下什么缺口？ | 客观提取 |
| 3 | 整体技术路线？分哪几个步骤？ | 客观提取 |
| 4 | 核心方法/模型/实验？关键参数？ | 客观提取 |
| 5 | 主要结论与关键定量结果？ | 客观提取 |
| 6 | 核心创新点？和已有研究最大区别？ | 客观+分析 |
| 7 | 局限性？哪些因素没考虑到？ | 客观+分析 |
| 8 | 针对本文不足，提出三个可落地的后续选题方向 | 分析+应用 |
| 9 | 作为同方向研究生，哪些部分值得逐句精读？为什么？ | 分析+应用 |
| 10 | 本文最容易被审稿人攻击的点是什么？ | 客观+分析 |

> 每问**必须保留**：置信度（高/中/低）与原文定位（第X节/页/图表，无法定位写"原文未明确"）。

## 每个问题的输出结构

```
### Q{n}. {问题}
- 类型：{类型}
- 置信度：高/中/低
- 原文定位：第X节 / 第X页 / 表X / 图X
- 精简版：1–2 句核心结论
- 详细回答：展开，保留关键数据

🔖 本问术语随查（就地附在本问后，不集中放最后）：
- 术语：一句中文解释（≤40字）
```

## 十问之后的两个工科必读模块

### 实验准备与流程
要点式简洁说明：实验/仿真对象与材料、关键设备、工况与边界条件、变量如何控制、执行步骤顺序。

### 重点图表导览
从 PDF 真实图注中挑 2–4 张最关键的图/表（编号不许编造）：
```
### Fig. 3（图）
- 为什么重点看：…
- 读图要点：该趋势/对比说明什么
```

## 读者自述引导问题（让用户自己写总结时逐条回答）

不要让用户写一段散文，引导他按这 5 个问题逐条写：
1. 一句话说清：解决什么具体问题？用了什么核心方法？得到什么关键数据？最终什么结论？
2. 结论在什么前提、什么参数范围、什么材料/体系下成立？外推边界在哪？
3. 梳理完整推理链：研究假设 → 实验设计 → 变量控制 → 数据结果 → 最终结论，每步证据是什么？
4. 本文哪个数据点/假设/图表最脆弱？让你复现会先验证哪一步？
5. 把方法搬到你自己的研究对象/工况上，哪些条件要改、哪些结论不能直接套？

## 评价四维度（evaluate 子命令）

1. 问题与结论把握准确度
2. 方法与推理链理解清晰度
3. 数据与边界条件意识
4. 批判与迁移思考深度

每项 25 分，合计 100 分。
